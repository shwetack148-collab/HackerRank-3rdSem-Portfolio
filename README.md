## Reflection

Through these HackerRank problems, I practiced algorithmic problem-solving using arrays, vectors, strings, loops, and hash maps. I learned that choosing an appropriate data structure can reduce unnecessary repeated operations. For example, using a frequency map for Sparse Arrays allows string occurrences to be stored and queried efficiently. Dynamic Array helped me understand how sequences can be organized and accessed using calculated indices. Diagonal Difference strengthened my understanding of matrix traversal and diagonal indexing. Time Conversion improved my handling of strings and conditional logic, while Compare the Triplets reinforced basic comparison and counting techniques. I also learned to consider both time and space complexity while writing solutions. These problems helped me understand how optimized algorithms can solve problems efficiently rather than relying only on straightforward approaches.
